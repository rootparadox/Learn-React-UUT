# ⚛️ Learn-React-UUT

Welcome to this repository! This project contains the materials and code examples I developed for teaching **React.js** to students at **Urmia University of Technology (UUT)**. 

The curriculum and projects are inspired by **Jonas Schmedtmann's Ultimate React Course**, structured specifically to help  students understand modern React development from the ground up.

---

## 📂 Repository Structure (Course Modules)

I have organized the code into specific sections to facilitate a step-by-step learning experience:

*   **`Pure-React`**: Introduction to React fundamentals and internal workings.
*   **`Components&Props`**: Deep dive into UI architecture and reusability.
*   **`State-Management`**: Explaining `useState` and efficient data flow patterns.
*   **`Class-Components`**: Teaching legacy patterns to ensure students can handle older codebases.
*   **`build-tools`**: Demonstrating the setup and configuration of React environments.

---
